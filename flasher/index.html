ESP32 USB to AirPrint

Biến máy in USB cũ thành máy in Wi-Fi (AirPrint, Mopria) bằng một board ESP32-S3. Trang này cài firmware lên board ngay trong trình duyệt, không cần cài phần mềm. Mã nguồn trên GitHub

Turn an old USB printer into a Wi-Fi printer (AirPrint, Mopria) with an ESP32-S3 board. This page installs the firmware from the browser; nothing to install on the computer. Source on GitHub

1Chuẩn bịWhat you need

  1. Board ESP32-S3 (ESP32 thường hoặc ESP32-C3 không dùng được). Nên chọn bản N16R8: 16 MB flash, 8 MB PSRAM. Flash phải từ 16 MB. Bấm vào đây để mua ESP32-S3 N16R8 (Shopee).
  2. Cắm board vào máy tính bằng cổng COM (có board ghi UART). Không cắm cổng ghi USB: cổng đó dành cho máy in. Board một cổng thì cắm cổng đó.
  3. Trình duyệt Chrome, Edge, Cốc Cốc hoặc Brave trên Windows, macOS hoặc Linux (mọi trình duyệt gốc Chromium đều được). Safari, Firefox và điện thoại không có Web Serial nên không nối được với board; khi đó nạp bằng esptool, xem mục Sự cố.
  4. Cáp USB có dây dữ liệu, không phải cáp chỉ sạc.
Không thấy cổng nào khi bấm Kết nối? Board dùng chip CH340 hoặc CP210x cần cài driver: CH340/CH343 · CP210x. Trên Linux, thêm user vào nhóm dialout rồi đăng nhập lại.
  1. An ESP32-S3 board (a plain ESP32 or an ESP32-C3 will not do). Prefer the N16R8 version: 16 MB flash, 8 MB PSRAM. The flash must be 16 MB or more. Buy an ESP32-S3 N16R8 here (Shopee, Vietnam).
  2. Plug the board into the computer by its COM port (UART on some boards). Not the port marked USB: that one is for the printer. A board with a single port: use that one.
  3. Chrome, Edge, Cốc Cốc or Brave on Windows, macOS or Linux (any Chromium-based browser works). Safari, Firefox and phones have no Web Serial, so they cannot talk to the board; flash with esptool instead, see Trouble.
  4. A USB cable with data wires, not a charge-only cable.
No serial port listed when you click Connect? Boards with a CH340 or CP210x chip need a driver: CH340/CH343 · CP210x. On Linux, add yourself to the dialout group and log in again.

2Cài firmwareInstall the firmware

Cách A: cài bản mới nhất bằng một nút. Bấm Cài đặt, chọn cổng của board (thường tên "USB Single Serial", "CH340", "CP210x" hoặc "USB JTAG/serial"), với board mới chọn xoá sạch (erase) khi được hỏi, rồi chờ. Trang tự kiểm tra board có đúng là ESP32-S3 không trước khi nạp.

Option A: one click, the latest build. Click Install, pick the board's port (usually "USB Single Serial", "CH340", "CP210x" or "USB JTAG/serial"), let it erase a new board when asked, and wait. The page checks that the board really is an ESP32-S3 before writing.

Trình duyệt này không cài được: mở trang bằng Chrome, Edge hoặc Cốc Cốc trên máy tính. This browser cannot install: open the page in Chrome, Edge or another Chromium browser on a computer. Trang cần https (hoặc localhost) mới nối được cổng USB. The page needs https (or localhost) to reach the USB port.

Cách B: nạp một file .bin bạn đã tải về. Tải esp32-usb-to-airprint.bin từ trang Releases (hoặc bản build mới nhất), rồi kéo thả file vào ô dưới hoặc bấm để chọn. Trang sẽ nối với board, kiểm tra chip là ESP32-S3, kiểm tra file đúng là ảnh đầy đủ, rồi nạp vào địa chỉ 0x0.

Option B: flash a .bin you downloaded. Get esp32-usb-to-airprint.bin from the Releases page (or the latest build), then drop it below or click to choose it. The page connects to the board, checks that the chip is an ESP32-S3 and that the file is a full image, then writes it at address 0x0.

Không kết nối được? Giữ nút BOOT trên board, bấm RST (hoặc EN), thả BOOT, rồi bấm lại. Đóng các chương trình khác đang mở cổng COM (Arduino, PlatformIO monitor).
Cannot connect? Hold the board's BOOT button, press RST (or EN), release BOOT, then try again. Close other programs that hold the COM port (Arduino, PlatformIO monitor).

3Nối board vào Wi-Fi nhà bạnConnect it to your Wi-Fi

  1. Sau khi nạp xong, board khởi động và phát mạng Wi-Fi riêng tên Printer-Setup-XXXX (XXXX khác nhau ở mỗi board).
  2. Trên điện thoại, nối vào mạng đó. Trang cài đặt tự mở (nếu không, mở http://192.168.4.1/).
  3. Chọn mạng Wi-Fi nhà (chỉ 2.4 GHz), nhập mật khẩu, đặt tên máy in và địa chỉ (ví dụ ip2700), bấm Connect.
  4. Board nối vào mạng nhà và khởi động lại, mạng Printer-Setup biến mất. Nối điện thoại lại mạng nhà, mở http://<địa chỉ>.local/.

Đổi mạng sau này: vào trang web của máy in, thẻ Cài đặt, bấm "Đổi mạng WiFi". Hoặc giữ nút BOOT trên board 10 giây.

  1. After the install the board starts and opens its own Wi-Fi network, Printer-Setup-XXXX (XXXX differs per board).
  2. On a phone, join that network. The setup page opens by itself (if not, open http://192.168.4.1/).
  3. Pick your home network (2.4 GHz only), type its password, give the printer a name and an address (e.g. ip2700), tap Connect.
  4. The board joins your network and restarts; Printer-Setup goes away. Back on your own Wi-Fi, open http://<address>.local/.

To change the network later: the printer's web page, Settings card, "Change WiFi network". Or hold the board's BOOT button for 10 seconds.

4Cắm máy inPlug in the printer

  1. Nối máy in vào cổng ghi USB của board bằng cáp USB-C sang USB-B (đầu vuông). Board một cổng: hàn thêm cổng USB-A cái vào GPIO19 (D-), GPIO20 (D+), 5V và GND.
  2. Hàn cầu "USB-OTG" trên board (hai pad nhỏ, thường ở mặt sau) để cổng USB có 5V. Máy in chỉ xuất hiện khi thấy 5V trên cáp.
  3. Cấp nguồn cho board bằng sạc điện thoại qua cổng COM. Bật máy in.
  4. Mở http://<địa chỉ>.local/: thấy tên máy in và trạng thái "Sẵn sàng" là xong. In từ iPhone, iPad, Mac (AirPrint), Android (Mopria) hoặc từ chính trang web.

Máy in báo lỗi (hết giấy, kẹt giấy, hết mực…) thì trang web hiện cửa sổ với mã lỗi và cách xử lý.

  1. Connect the printer to the board's port marked USB with a USB-C to USB-B cable. A single-port board: solder a USB-A socket to GPIO19 (D-), GPIO20 (D+), 5V and GND.
  2. Bridge the "USB-OTG" solder pads on the board (two small pads, usually underneath) so that the USB port carries 5 V. The printer only shows up when it sees 5 V on the cable.
  3. Power the board from a phone charger on the COM port. Turn the printer on.
  4. Open http://<address>.local/: the printer's name and "Ready" mean you are done. Print from iPhone, iPad, Mac (AirPrint), Android (Mopria) or from the web page itself.

When the printer reports an error (out of paper, jam, no ink…) the web page shows a window with the code and how to fix it.

The page says the chip is not an ESP32-S3The board is a plain ESP32, an S2 or a C3. The firmware runs on the ESP32-S3 only.
Installed, but no Printer-Setup networkWait 20 seconds after the install. The board may be joining a network saved earlier: check its LED, or hold BOOT for 10 seconds to reopen the setup network.
Joined the setup network, the page does not openOpen a browser at http://192.168.4.1/. Turn mobile data off if the phone keeps switching networks.
